# Console Binaurale

Console per comporre suoni binaurali e di rilassamento direttamente nel browser. Gratuita, senza registrazione, nessun dato raccolto.

**Usala qui:** https://guro-vibe.github.io/console-binaurale/

Ascolta in cuffia. Non è un dispositivo medico: leggi le avvertenze nella console.
